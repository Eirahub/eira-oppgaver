# Om oppgaven {.activity}

Elevene lærer å åpne programmer, minimere, maksimere og lukke vinduer, flytte og
endre størrelse, bytte vindu og legge to vinduer side om side.

Det siste er nyttig i resten av kodeklubben: oppgaveteksten på den ene siden,
Scratch eller kodeprogrammet på den andre.

## Oppgaven passer til: {.check}

__Fag__: Teknologi, digitale ferdigheter

__Anbefalte trinn__: 4. til 10. trinn, for elever uten erfaring med PC

__Tema__: Vinduer, grunnleggende datakunnskap

__Tidsbruk__: 30 minutter

## Kompetansemål {.challenge}

Ikke satt. Se [udir.no](https://www.udir.no/lk20/).

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan bytte mellom vinduer med musa og med `Alt+Tab`.

- [ ] Eleven kan legge to vinduer side om side.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: [Musa](../musa/musa.html) og
  [Tastaturet](../tastaturet/tastaturet.html).

- [ ] __Utstyr__: PC med Windows 11 eller Linux.

### Tips til veiledere

- På iPad er det bare én app om gangen. Mange barn tror programmet er borte når
  vinduet er minimert. Vis at ikonet på oppgavelinjen eller i Dock fortsatt er
  merket.

- Krysset på en fane og krysset på vinduet blir ofte blandet. Vis forskjellen.

- Mange drar i feil del av vinduet og merker tekst i stedet. Vis tittellinjen.

- Små skjermer gjør side om side trangt. Bruk `Ctrl+-` i nettleseren for å få
  plass.

### Windows og Linux

- Windows 11: `Windows-tasten+←` og `→` legger vinduet på en halvdel, og
  Snap-hjelp (Snap Assist) viser de andre vinduene. Hold pekeren over
  maksimer-knappen, eller trykk `Windows-tasten+Z`, for å få Snap-oppsett (Snap
  layouts). `Windows-tasten+↑` maksimerer.

- Ubuntu (GNOME): `Super+←` og `Super+→` legger vinduet på en halvdel. `Super+↑`
  maksimerer. `Super+Tab` og `Alt+Tab` bytter vindu. Ubuntu har knappene
  minimer, maksimer og lukk. Ren GNOME uten Ubuntu sine tillegg viser bare lukk.
  Andre skrivebord (KDE, Cinnamon på Linux Mint) har tre knapper og en
  oppgavelinje nederst, mer likt Windows.
