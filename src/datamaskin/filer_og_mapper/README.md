# Om oppgaven {.activity}

Elevene lærer hva en fil og en mappe er, og bruker filbehandleren til å lage
mapper, lagre, gi nytt navn, flytte, slette og hente tilbake fra papirkurven. De
lærer også hva en filendelse er.

Dette er ofte det største spranget for barn fra iPad, der alt ligger inne i
appen og lagres av seg selv.

## Oppgaven passer til: {.check}

__Fag__: Teknologi, digitale ferdigheter

__Anbefalte trinn__: 4. til 10. trinn, for elever uten erfaring med PC

__Tema__: Filer, mapper, grunnleggende datakunnskap

__Tidsbruk__: 45 minutter

## Kompetansemål {.challenge}

Ikke satt. Se [udir.no](https://www.udir.no/lk20/).

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan lagre en fil i en bestemt mappe og finne den igjen.

- [ ] Eleven kan slette en fil og hente den tilbake fra papirkurven.

### Tips til veiledere

- Bruk bildet med en perm og ark. Mappen er permen, filene er arkene.

- Lagre-vinduet er vanskelig. Mange trykker Lagre uten å se hvor. Be dem lese
  hvilken mappe som er valgt, høyt.

- Delte maskiner: Avtal hvor elevene skal lagre, for eksempel
  `Dokumenter/Kodeklubben`. Lag gjerne mappen på forhånd hvis tiden er knapp.

- Synkroniserte mapper: På Windows kan Dokumenter ligge i OneDrive. Da ser stien
  annerledes ut, men det virker likt.

- Si fra om `Shift+Delete`. Den sletter uten papirkurv.

### Windows og Linux

- Windows 11: Filutforsker åpnes med `Windows-tasten+E`. Ny mappe:
  `Ctrl+Shift+N`. Gi nytt navn: `F2`. `Delete` flytter til papirkurven.
  Gjenopprett: åpne Papirkurv, høyreklikk og velg **Gjenopprett** (Restore). Vis
  filendelser: **Vis**, **Vis**, **Filnavnutvidelser** (View, Show, File name
  extensions).

- Ubuntu (GNOME Filer): `F2` gir nytt navn og merker bare navnet, ikke
  filendelsen. `Delete` flytter til papirkurven, og en knapp for å angre vises
  noen sekunder. Gjenopprett: **Papirkurv** i sidepanelet, velg filen og
  **Gjenopprett fra papirkurven** (Restore From Trash). `Ctrl+H` viser skjulte
  filer. Andre filbehandlere på Linux (Dolphin, Nemo) har samme begreper:
  hjemmemappe, papirkurv og høyreklikkmeny.
