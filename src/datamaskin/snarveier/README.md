# Om oppgaven {.activity}

Elevene lærer å merke tekst og bruke snarveiene for kopier, klipp ut, lim inn,
angre, merk alt, lagre, finn og zoom. Snarveiene er like på Windows og Linux.

Øvelsen [Øv på snarveier](ovelse_snarveier.html) sjekker at eleven har kopiert,
klippet ut og angret riktig.

## Oppgaven passer til: {.check}

__Fag__: Teknologi, digitale ferdigheter

__Anbefalte trinn__: 4. til 10. trinn, for elever uten erfaring med PC

__Tema__: Hurtigtaster, grunnleggende datakunnskap

__Tidsbruk__: 30 minutter

## Kompetansemål {.challenge}

Ikke satt. Se [udir.no](https://www.udir.no/lk20/).

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan kopiere, klippe ut og lime inn med tastaturet.

- [ ] Eleven bruker `Ctrl+Z` når noe går galt.

### Tips til veiledere

- Mange slipper Ctrl før de trykker bokstaven. Vis: hold, trykk, slipp begge.

- `Ctrl+Z` er verdt å lære først. Den redder mye frustrasjon i Scratch og når de
  koder.

- Lag gjerne en lapp med snarveiene som ligger ved maskinen.

- Øvelse 5 (zoom) oppdager endringen i de fleste nettlesere. Hvis ikke, kan
  eleven trykke på knappen "Jeg fikk det til".

- I terminalen på Linux er kopier og lim inn `Ctrl+Shift+C` og `Ctrl+Shift+V`.
  Det trengs ikke i dette kurset, men kan komme opp senere.
