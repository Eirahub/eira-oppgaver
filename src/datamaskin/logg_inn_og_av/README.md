# Om oppgaven {.activity}

Elevene lærer hva en brukerkonto er, hvordan de passer på passordet, og
forskjellen på å låse, logge av og slå av.

## Oppgaven passer til: {.check}

__Fag__: Teknologi, digitale ferdigheter, samfunnsfag (nettvett)

__Anbefalte trinn__: 4. til 10. trinn, for elever uten erfaring med PC

__Tema__: Brukerkontoer, passord, personvern

__Tidsbruk__: 20 minutter

## Kompetansemål {.challenge}

Ikke satt. Se [udir.no](https://www.udir.no/lk20/).

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan låse skjermen og logge av.

- [ ] Eleven kan forklare hvorfor passord skal holdes hemmelig.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: [Tastaturet](../tastaturet/tastaturet.html).

- [ ] __Utstyr__: PC med en konto per elev eller en felles elevkonto.

## Fremgangsmåte

[Klikk her for å se oppgaveteksten.](logg_inn_og_av.html)

### Tips til veiledere

- Bestem på forhånd hvordan kontoene skal være: én per elev, eller en felles
  konto uten adminrettigheter. Skriv aldri passord på tavla eller på lapper ved
  maskinene.

- Har dere en felles elevkonto, bør filene ryddes jevnlig, så ingen ser andres
  arbeid.

- Barn bruker ofte samme passord overalt. Snakk om at klubbkontoen skal ha sitt
  eget.

- Vis at lås beholder alt, mens logg av lukker programmene. Lagre først!

### Windows og Linux

- Windows 11: `Windows-tasten+L` låser. Logg av: **Start**, klikk på kontoen
  (navnet eller bildet), **Logg av** (Sign out). `Ctrl+Alt+Delete` gir også
  valgene Lås og Logg av.

- Ubuntu (GNOME): `Super+L` låser. Logg av: systemmenyen øverst til høyre,
  av/på-knappen, **Logg ut** (Log Out). **Bytt bruker** vises bare når maskinen
  har mer enn én konto. Andre Linux-skrivebord har de samme valgene i
  hovedmenyen, men snarveien for å låse kan være en annen.
