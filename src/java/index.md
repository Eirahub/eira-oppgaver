Java er et av verdens mest brukte programmeringsspråk. Det brukes i store
systemer i banker og butikker, i Android-apper og i spill. I dette kurset lærer
du Java i **IntelliJ IDEA**, det samme programmet som proffene bruker. Det er
gratis.

Alle oppgavene handler om klosser, inventar og monstre, men alt skjer som tekst
på skjermen. Kurset passer fra 8. trinn og oppover, og du trenger ikke ha
programmert før.

Kurset er laget som forberedelse til å lage egne modder til Minecraft Java
Edition. Første del lærer deg det grunnleggende i Java. Andre del lærer deg
akkurat det du trenger når du skal lage modder: klasser, arv, lambdaer, registre
og Gradle.

## Hvordan komme i gang

- Installer IntelliJ IDEA og Java 25. [Her er installasjonen steg for
  steg](installasjon/installasjon.html).

- Begynn med oppgaven `Hei, Java!`, og ta oppgavene i rekkefølge.

- Hver oppgave lærer deg én ny snarvei i IntelliJ. Bruk dem, så går alt raskere.

- Velg filteret **Oppgavesamlinger** for å se de to delene av kurset: `Java fra
  start` og `Java for moddere`.

Minecraft er et varemerke som tilhører Mojang Synergies AB. Kurset er ikke laget
av eller godkjent av Mojang eller Microsoft.
