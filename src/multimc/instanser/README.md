# Om oppgaven {.activity}

Elevene lager instanser for to Minecraft-versjoner (26.3 og 1.21.11), bytter
versjon, kopierer en instans og finner mappene til en instans. De setter også
minnegrensen. Oppgaven gir den orden som trengs før de skal teste modder i
mange oppsett.

## Oppgaven passer til: {.check}

__Fag__: Teknologi, informasjonsteknologi

__Anbefalte trinn__: 8. trinn til VG3

__Tema__: Minecraft, versjoner, filstruktur

__Nivå__: 1

__Tidsbruk__: Omtrent en time. Hver versjon lastes ned første gang den startes.

## Kompetansemål {.challenge}

Kompetansemål er ikke knyttet til oppgaven ennå. Hent eventuelle mål fra
[læreplanen i informasjonsteknologi på
udir.no](https://www.udir.no/lk20/inf01-02) som passer for gruppa.

## Forslag til læringsmål {.challenge}

- [ ] Elevene kan forklare hva en instans er, og hvorfor man har flere.

- [ ] Elevene kan lage, gi nytt navn, gruppere og kopiere instanser.

- [ ] Elevene kan finne mappene `mods`, `saves`, `logs` og `crash-reports`.

- [ ] Elevene kan forklare hvorfor man tar en kopi før man bytter til en eldre
  versjon.

## Forslag til vurderingskriterier {.challenge}

- [ ] Eleven oppnår middels måloppnåelse ved å lage de to instansene og starte
  dem.

- [ ] Eleven oppnår høy måloppnåelse ved å forklare hva som er felles og ulikt
  mellom en original og en kopi, og ved å løse utfordringene.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: Oppgavene Installasjon og Java for Minecraft.

- [ ] __Utstyr__: MultiMC med innlogget konto, og Java 21 og Java 25 installert.
  Oppgaven sier at 26.3 trenger Java 25 og 1.21.11 trenger Java 21.

- [ ] __Minne__: Oppgaven foreslår 4096 MB som maksimum for testinstanser. Sjekk
  at elevmaskinene har nok. Minecraft bør ikke få mer enn halvparten av minnet.

- [ ] __Disk__: Hver versjon og hver kopi tar plass. Sjekk ledig diskplass,
  særlig på delte skolemaskiner og profiler med kvote.


# Fremgangsmåte {.activity}

## Steg 1 og 2: Instanser og Java {.check}

- [ ] Be elevene bruke samme navnemønster (`Vanilla 26.3`), så det blir lett å
  hjelpe dem.

- [ ] Det vanligste problemet er feil Java. Versjonen står nederst til venstre i
  hovedmenyen i spillet, og Java velges i innstillingene til instansen.

## Steg 3: Bytt versjon {.check}

- [ ] Understrek at verdener fra en nyere versjon kan bli ødelagt i en eldre.
  La elevene teste med en kopi, ikke med en verden de bryr seg om.

## Steg 4 og 5: Kopier og mapper {.check}

- [ ] Elever forveksler lett mappa til MultiMC og `.minecraft` i instansen. Bruk
  knappene Instance Folder og Open .minecraft i stedet for å lete.

- [ ] Mappen `mods` finnes ikke alltid før en mod er lagt til. Sjekk hva som
  faktisk ligger i mappa før du leter etter feil.

## Steg 6: Minne {.check}

- [ ] La elevene sjekke hvor mye minne maskinen har før de skriver en verdi.

- [ ] En for høy grense gir tregere maskin, ikke raskere spill.

## Vanlige problemer {.protip}

- Instansen viser feil versjon: eleven valgte feil versjon i lista.

- Kopien mangler verdenene fra originalen: eleven glemte å krysse av for Copy
  saves.

- Feil instans slettet: sletting kan ikke angres, så minn dem på å lese navnet
  to ganger.


# Variasjoner {.activity}

- La elevene lage et eget navnesystem og diskutere hva som fungerer best.

- Kjør et snapshot i en egen instans og sammenlign med vanlig versjon.

- La klassen lage en felles navnestandard for klubbens testinstanser.
