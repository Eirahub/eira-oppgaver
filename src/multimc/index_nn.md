Har du laga ein mod, vil du vite at han verkar hos andre. Spelarane brukar ulike
mod-loadarar og ulike versjonar av Minecraft. I dette kurset lærer du å teste
moden din med **MultiMC**, ein gratis launcher for Minecraft Java Edition.

I MultiMC lagar du éin **instans** for kvar kombinasjon du vil teste, til
dømes Fabric med Minecraft 26.3 og NeoForge med 1.21.11. Kvar instans har si
eiga mappe med moddar, verder og innstillingar, og sin eigen Java. Då kan du
prøve moden i mange oppsett utan at dei øydelegg for kvarandre.

Kurset passar frå 8. trinn og oppover. Det passar godt etter kurset [Lag din
eigen Minecraft-mod](../minecraft_mod), som lagar moden `rubinmod`. Du kan òg
bruke kurset til å teste andre moddar.

## Før du startar

- Du treng **Minecraft Java Edition** og ein Microsoft-konto som eig spelet. Er
  du under 18 år, kan det hende ein forelder må logge inn eller gi lov.

- Du treng ei datamaskin med Windows, macOS eller Linux, og lov til å
  installere program. Installasjonen er ein jobb for ein vaksen eller saman
  med ein vaksen.

- Til oppgåva **Test moden** treng du jar-filene frå kurset [Lag din eigen
  Minecraft-mod](../minecraft_mod). Har du ikkje laga ein mod, kan du bruke ein
  mod frå [Modrinth](https://modrinth.com) i staden.

## Korleis kome i gang

- Byrj med [Installasjon](installasjon/installasjon.html) og [Java for
  Minecraft](java_for_minecraft/java_for_minecraft.html). Oppgåvene finst
  berre på bokmål førebels.

- Ta oppgåvene i rekkjefølgje. Vel filteret **Oppgåvesamlingar** for å sjå dei i
  rekkjefølgje.

## Oppgåvene

1. **Installasjon**: installer MultiMC, logg inn og start vanleg Minecraft.

2. **Java for Minecraft**: kva Java kvar Minecraft-versjon treng, og korleis du
  installerer han.

3. **Instansar og versjonar**: lag, kopier og rydd instansar for fleire
  Minecraft-versjonar.

4. **Mod-loadarar**: Fabric, NeoForge, Forge og Quilt i kvar sin instans.

5. **Test moden**: legg jar-filene i rette instansar og fyll ut ein testplan.

6. **Loggar og krasjrapportar**: finn feilen når spelet krasjar, og del ein
  logg trygt.

7. **Modpakkar**: eksporter ein instans, så alle i klubben får same oppsett.
