# Om oppgaven {.activity}

Elevene laster ned MultiMC, logger inn med Microsoft-kontoen som eier Minecraft
Java Edition, og starter en instans med vanlig Minecraft. MultiMC er en
launcher som lar elevene ha mange adskilte oppsett (instanser) av spillet.
Oppgaven er første trinn i kurset og krever ingen programmering.

## Oppgaven passer til: {.check}

__Fag__: Teknologi, informasjonsteknologi, valgfag programmering (som
forberedelse)

__Anbefalte trinn__: 8. trinn til VG3

__Tema__: Minecraft, launcher, kontoer og digital sikkerhet

__Nivå__: 1

__Tidsbruk__: Omtrent en halvtime per elev. Første nedlasting av Minecraft kan
ta lenger tid når mange gjør det samtidig.

## Kompetansemål {.challenge}

Kompetansemål er ikke knyttet til oppgaven ennå. Hent eventuelle mål fra
[læreplanen i informasjonsteknologi på
udir.no](https://www.udir.no/lk20/inf01-02) som passer for gruppa.

## Forslag til læringsmål {.challenge}

- [ ] Elevene kan forklare hva en launcher og en instans er.

- [ ] Elevene kan laste ned programvare fra den offisielle nettsida og forklare
  hvorfor kopier på andre sider kan være en risiko.

- [ ] Elevene kan logge inn med Microsoft-konto uten å skrive passordet i andre
  programmer enn Microsofts egen nettside.

- [ ] Elevene kan lage en instans og starte Minecraft fra den.

## Forslag til vurderingskriterier {.challenge}

- [ ] Eleven oppnår middels måloppnåelse ved å fullføre oppgaven og starte
  vanlig Minecraft fra MultiMC.

- [ ] Eleven oppnår høy måloppnåelse ved å forklare hvorfor innloggingen skjer
  på Microsofts nettside, og hva MultiMC får og ikke får vite.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: Ingen.

- [ ] __Konto__: Hver elev trenger en Microsoft-konto som eier Minecraft Java
  Edition. Bedrock Edition og Education Edition virker ikke. Planlegg for elever
  som ikke eier spillet, for eksempel ved at de følger med en som gjør det.

- [ ] __Maskin__: Windows, macOS eller Linux der elevene får installere og pakke
  ut programmer. Oppgaven anbefaler minst 8 GB minne. Låste skolemaskiner kan
  kreve hjelp fra IT.

- [ ] __Java__: MultiMC har ikke med Java. Den installeres i oppgaven Java for
  Minecraft, så ta den før eller sammen med denne.

- [ ] __Nett__: Minecraft og bibliotekene lastes ned første gang. Test at
  nettverket slipper gjennom multimc.org, Microsoft-innlogging og
  nedlastingene fra Mojang.


# Fremgangsmåte {.activity}

## Før timen {.check}

- [ ] Prøv hele oppgaven på en av maskinene elevene skal bruke. Da oppdager du
  låste mapper og brannmurer.

- [ ] Avklar hvem som eier Minecraft. Elever under 18 år kan trenge at en
  forelder logger inn eller godkjenner. Si fra i forkant.

- [ ] Ta kontakt med IT hvis nettverket filtrerer nedlastinger.

## Steg 2: Last ned {.check}

- [ ] Hold fast på at MultiMC bare lastes ned fra multimc.org.

- [ ] Mappa må ligge et sted eleven kan skrive til. Programfiler fungerer ikke.
  En mappe som synkes med OneDrive eller Google Disk gjør spillet tregt.

- [ ] Varsler MultiMC om en midlertidig mappe, er zip-fila ikke flyttet ut av
  nedlastingsmappa. Pakk ut på nytt et fast sted.

## Steg 3 og 4: Første start og innlogging {.check}

- [ ] Be elevene velge engelsk språk. Oppgavene bruker engelske navn på knapper
  og menyer.

- [ ] Innloggingen starter i MultiMC og avsluttes i nettleseren. La elevene
  sjekke at adressen er en Microsoft-side før de skriver noe.

- [ ] Skole- og barnekontoer kan stoppes av foreldrekontroll eller skolens egne
  regler. Avklar lokalt hva som er tillatt.

## Steg 5: Første instans {.check}

- [ ] Første nedlasting av Minecraft tar tid. Si at det er normalt, og at neste
  start går raskt.

- [ ] En feilmelding om Java betyr at Java mangler eller er feil. Henvis til
  oppgaven Java for Minecraft.

- [ ] Launch Offline krever likevel at eleven har logget inn med en konto som
  eier spillet.

## Vanlige problemer {.protip}

- Innloggingen er ferdig, men MultiMC viser ingen konto: prøv å legge til
  kontoen på nytt, og sjekk at kontoen eier Minecraft Java Edition.

- Spillet starter ikke og ingen melding vises: se i Minecraft Log, og ta
  oppgaven Logger og krasjrapporter.

- Sikkerhetsprogram blokkerer MultiMC: les varselet og ta kontakt med IT. Ikke
  be elevene slå av sikkerhetsprogram selv.


# Variasjoner {.activity}

- La elevene lage instanser av en nyere og en eldre versjon, og se versjonen i
  hovedmenyen.

- La elevene sammenligne MultiMC med den vanlige Minecraft Launcher. Hva er
  likt, og hva er ulikt?

- Bruk innloggingen som utgangspunkt for en samtale om digital sikkerhet:
  hvorfor
  skal man aldri gi fra seg passordet, selv til noen som vil hjelpe?
