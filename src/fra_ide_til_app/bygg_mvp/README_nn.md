# Om oppgåva {.activity}

Eleven byggjer MVP-en med Claude Code i ei fast løkke: eitt steg, test, commit.
Eleven øver på å beskrive feil, lese endringar, gå tilbake med Git og sjekke
universell utforming.

## Oppgåva passar til: {.check}

__Fag__: Informasjonsteknologi, programmering, sal, service og reiseliv

__Tilrådde trinn__: Vidaregåande

__Tema__: KI-assistert utvikling, testing, feilsøking, versjonskontroll,
universell utforming

__Tidsbruk__: 2 til 4 timar, gjerne over fleire økter

## Kompetansemål {.challenge}

- [ ] __Informasjonsteknologi 2__: vurdere og bruke strategier for feilsøking og
  testing av programkode

- [ ] __Informasjonsteknologi 1__: lagre og hente fram data, presentere data på
  nettsider og reflektere over hvordan representasjonsform kan påvirke
  tolkningen

- [ ] __Vg2 salg, service og reiseliv__: bruke digitale system og plattformer
  til å rettleie, informere, kommunisere og følgje opp kundar, brukarar, gjester
  og kollegaer

## Forslag til vurderingskriterium {.challenge}

Git-historikken viser små steg med forståelege meldingar. Eleven kan vise éin
feil dei fekk retta, og forklare korleis dei beskreiv han. MVP-en dekkjer
historiene i `PLAN.md` og er sjekka for universell utforming.

### Tips til rettleiarar

- Commit etter kvart steg er det som gjer at elevane tør å la KI-en endre ting.
  Sjekk Git-historikken undervegs.

- Når ein elev sit fast: be dei lese meldinga si høgt. Ofte er ho utydeleg.

- Elevar som har brukt KI mykje, vil gjerne be om heile appen på ein gong. La
  dei prøve, og samanlikn med løkka. Det gir ein god samtale om kontroll og
  kvalitet.

- Utfordringa sender kundedata ut av nettlesaren. Bruk skjemaverktøyet som
  skulen har godkjent, og snakk om kven som får sjå dataa.

- Elevar under 18 kan gjere oppgåva med læraren ved tastaturet, eller med
  GitHub Copilot Free eller KI-verktøyet som skulen har godkjent.
