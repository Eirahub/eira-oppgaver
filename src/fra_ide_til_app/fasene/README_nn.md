# Om oppgåva {.activity}

Eleven får ei oversikt over fasane i kurset, frå behov til avvikling, med
kjenneteikn, kva som blir laga, ferdigkriterium og oppgåvene som høyrer til.
Eleven lærer skilnaden på å vere ferdig med ein fase og ferdig med ei sak, at
kvar fase kan bli ein milepæl i GitHub, og at det er vanleg å gå tilbake til ein
tidlegare fase.

## Oppgåva passar til: {.check}

__Fag__: Entreprenørskap og bedriftsutvikling, informasjonsteknologi, sal,
service og reiseliv

__Tilrådde trinn__: Vidaregåande

__Tema__: Innovasjonsprosess, prosjektfasar, ferdigkriterium

__Tidsbruk__: 30 til 45 minutt

## Kompetansemål {.challenge}

- [ ] __Entreprenørskap og bedriftsutvikling 1__: utforske og bruke ulike
  innovasjonsprosessar ved etablering av verksemder

- [ ] __Entreprenørskap og bedriftsutvikling 2__: vurdere bruk av prosjekt og
  andre samarbeidsformer og betydninga nettverksbygging har i utvikling av
  verksemder

- [ ] __Informasjonsteknologi 2__: velge og bruke relevante
  systemutviklingsmetoder og -verktøy for samarbeid med andre

## Forslag til vurderingskriterium {.challenge}

Eleven kan seie kva fase prosjektet er i, kva som manglar før neste fase, og
forklare skilnaden på ferdigdefinisjonen for ei sak og ferdigkriteria for ein
fase.

## Føresetnader og utstyr {.challenge}

- [ ] __Føresetnader__: Ingen.

- [ ] __Utstyr__: Ingen. Oppgåva kan lesast på skjerm eller skrivast ut.

### Tips til rettleiarar

- Bruk tabellen som eit kart gjennom heile kurset. Be elevane seie kva fase dei
  er i ved starten av kvar økt.

- Ferdigkriteria står som sjekkliste i den siste oppgåva i kvar fase. La
  elevane vise fram sjekklista før dei går vidare. Det er eit naturleg punkt
  for undervegsvurdering.

- Snakk om at det er bra å gå tilbake. Ei gruppe som oppdagar i kundetesten at
  ideen ikkje held, har lært meir enn ei gruppe som aldri testa.

- Tala i ferdigkriteria er eit minimum. Sterke grupper kan intervjue og teste
  med fleire.

- Milepælar og prosjekttavle krev GitHub, og GitHub krev 13 år. Elevar utan
  konto kan bruke eit ark med tre kolonnar og lappar.

### Kva er testa

Oppgåva er skriven i november 2026 og er ikkje prøvd med elevar enno.
