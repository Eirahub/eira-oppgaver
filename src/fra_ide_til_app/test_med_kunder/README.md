# Om oppgaven {.activity}

Eleven publiserer MVP-en, gjennomfører brukertest med tre kunder, prioriterer
tilbakemeldingene, lager neste versjon og holder en pitch på to minutter.

## Oppgaven passer til: {.check}

__Fag__: Salg, service og reiseliv, entreprenørskap og bedriftsutvikling,
informasjonsteknologi

__Anbefalte trinn__: Videregående

__Tema__: Publisering, brukertest, prioritering, pitch

__Tidsbruk__: 2 til 3 timer, pluss tid til kundetest

## Kompetansemål {.challenge}

- [ ] __Vg2 salg, service og reiseliv__: presentere et produkt som
  representerer innovasjon og nyskaping, og gjøre rede for hvilken rolle
  lønnsomhet, klima og etiske forhold har spilt i utviklingen

- [ ] __Vg1 salg, service og reiseliv__: selge et produkt og gjøre rede for
  salgsprosessen

- [ ] __Informasjonsteknologi 2__: vurdere brukervennligheten i egne og andres
  programmer og foreslå forbedringer

## Forslag til vurderingskriterier {.challenge}

Appen er publisert, eleven har notater fra tre brukertester, og neste versjon
bygger på det kundene sa. Pitchen har alle fem delene og holder tiden.

### Tips til veiledere

- GitHub Pages er gratis, men vilkårene tillater ikke nettsider som driver en
  bedrift eller nettbutikk. Det er greit for testing og skoleprosjekter. Se
  [Hvilken type app?](../typer_apper/typer_apper) for alternativer i ekte
  drift.

- Repoet på GitHub blir offentlig. Sjekk at det ikke inneholder navn,
  telefonnumre eller intervjunotater.

- Pitchen passer godt inn i messer og konkurranser for elevbedrifter.
