# Om oppgaven {.activity}

Eleven lærer de første kommandoene i terminalen, installerer Claude Code,
skriver en `CLAUDE.md` med regler for prosjektet og bruker plan-modus til å få
en plan før KI-en skriver kode.

## Oppgaven passer til: {.check}

__Fag__: Informasjonsteknologi, programmering

__Anbefalte trinn__: Videregående

__Tema__: Terminal, KI-assistert utvikling, prosjektregler, planlegging

__Tidsbruk__: 60 minutter

## Kompetansemål {.challenge}

- [ ] __Informasjonsteknologi 2__: velge og bruke relevante
  systemutviklingsmetoder og -verktøy for samarbeid med andre

- [ ] __Informasjonsteknologi 1__: utforske, strukturere og kommentere
  programkode

## Forslag til vurderingskriterier {.challenge}

Eleven kan forklare hva terminalen er, har en `CLAUDE.md` med egne regler, og
har lest og justert planen fra Claude Code før den ble godkjent.

### Tips til veiledere

- Les [Veiledning for
  lærere](../veiledning_for_laerere/veiledning_for_laerere) om risiko,
  kontoer og ansvar i kurset før du starter.

- Claude Code er bare et eksempel. Elevene kan bruke andre verktøy, som
  Gemini, GitHub Copilot eller ChatGPT. Stegene blir litt annerledes, men
  `PLAN.md`, reglene og «plan før kode» virker likt.

- Elevene sjekker selv aldersgrense, pris og vilkår. Er eleven under
  aldersgrensen, kan en forelder eller lærer stå som ansvarlig for kontoen.
  Læreren kan også kjøre verktøyet på storskjerm mens elevene bestemmer hva
  det skal få beskjed om. Rollene kan byttes: én elev skriver beskjeden, én
  leser planen høyt, én sjekker mot `PLAN.md`.

- Sjekk at installasjonen virker på skolens maskiner før timen. Skolemaskiner
  kan stoppe skript i PowerShell.

- Snakk om tillatelser: Claude Code spør før den endrer filer eller kjører
  kommandoer. Elevene skal lese spørsmålet, ikke bare trykke ja.

### Hva er testet

Kommandoene er fra dokumentasjonen til Claude Code i november 2026. Oppgaven er
ikke prøvd med elever ennå.
