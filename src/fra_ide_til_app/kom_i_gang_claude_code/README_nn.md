# Om oppgåva {.activity}

Eleven lærer dei første kommandoane i terminalen, installerer Claude Code,
skriv ein `CLAUDE.md` med reglar for prosjektet og bruker planmodus til å få
ein plan før KI-en skriv kode.

## Oppgåva passar til: {.check}

__Fag__: Informasjonsteknologi, programmering

__Tilrådde trinn__: Vidaregåande

__Tema__: Terminal, KI-assistert utvikling, prosjektreglar, planlegging

__Tidsbruk__: 60 minutt

## Kompetansemål {.challenge}

- [ ] __Informasjonsteknologi 2__: velge og bruke relevante
  systemutviklingsmetoder og -verktøy for samarbeid med andre

- [ ] __Informasjonsteknologi 1__: utforske, strukturere og kommentere
  programkode

## Forslag til vurderingskriterium {.challenge}

Eleven kan forklare kva terminalen er, har ein `CLAUDE.md` med eigne reglar, og
har lese og justert planen frå Claude Code før han vart godkjend.

### Tips til rettleiarar

- Claude Code krev at brukaren er 18 år og har betalt abonnement eller
  API-tilgang. Med elevar under 18 køyrer læraren Claude Code på storskjerm,
  og elevane bestemmer kva han skal få beskjed om. Rollene kan byttast: éin
  elev skriv beskjeden, éin les planen høgt, éin sjekkar mot `PLAN.md`.

- Gratis alternativ: KI-verktøyet skulen har godkjent, eller GitHub Copilot
  Free i VS Code (krev GitHub-konto, 13 år). Stega blir litt annleis, men
  `PLAN.md`, reglane og «plan før kode» verkar likt.

- Sjekk at installasjonen verkar på maskinene til skulen før timen.
  Skulemaskiner kan stoppe skript i PowerShell.

- Snakk om løyve: Claude Code spør før han endrar filer eller køyrer
  kommandoar. Elevane skal lese spørsmålet, ikkje berre trykkje ja.

### Kva er testa

Kommandoane er frå dokumentasjonen til Claude Code i november 2026. Oppgåva er
ikkje prøvd med elevar enno.
