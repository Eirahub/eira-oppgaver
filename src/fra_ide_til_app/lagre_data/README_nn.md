# Om oppgåva {.activity}

Eleven vel kvar appen skal lagre data (nettlesar, skjema eller rekneark,
database), lærer kva det betyr for tilgang, kostnad og risiko, og sjekkar den
vanlegaste feilen i appar laga med KI: data som ligg ope fordi nøklar og
tilgangsreglar er feil.

## Oppgåva passar til: {.check}

__Fag__: Informasjonsteknologi, programmering

__Tilrådde trinn__: Vidaregåande

__Tema__: Datalagring, frontend og backend, database, tilgangsreglar,
løyndomar, personvern

__Tidsbruk__: 90 til 120 minutt

## Kompetansemål {.challenge}

- [ ] __Informasjonsteknologi 1__: lagre og hente fram data, presentere data på
  nettsider og reflektere over hvordan representasjonsform kan påvirke
  tolkningen

- [ ] __Informasjonsteknologi 1__: gjøre rede for og vurdere hvordan ulike typer
  informasjon kan representeres digitalt og struktureres ved hjelp av ulike
  datalagringsmetoder

- [ ] __Informasjonsteknologi 2__: gjøre rede for standarder for lagring,
  utveksling og sikring av ulike typer data

- [ ] __Informasjonsteknologi 1__: gjøre rede for gjeldende
  personvernregelverk og hvilke konsekvenser det har for utvikling av
  informasjonsteknologi

## Forslag til vurderingskriterium {.challenge}

Valet av lagring er grunngitt i `PLAN.md`. Eleven kan forklare kven som ser
dataa, og har sjekka at ingen løynde nøklar ligg i nettlesaren. Med database
har eleven testa at éin brukar ikkje ser dataa til ein annan.

## Føresetnader og utstyr {.challenge}

- [ ] __Føresetnader__: [Bygg MVP-en](../bygg_mvp/bygg_mvp_nn) og [Tryggleik og
  risiko](../sikkerhet_og_risiko/sikkerhet_og_risiko_nn), steg 1 til 3.

- [ ] __Utstyr__: PC med VS Code, Git, nettlesar og ein KI-kodeassistent.

## Framgangsmåte

### Tips til rettleiarar

- Les [Rettleiing for
  lærarar](../veiledning_for_laerere/veiledning_for_laerere_nn) om risiko,
  kontoar og ansvar i kurset før du startar.

- Appar på nivå 1 og 2 kan hoppe over oppgåva. Steg 5 er likevel nyttig for
  alle som skal publisere noko.

- Bruk skjemaverktøyet som skulen har godkjent, i steg 3, og snakk om kven som
  får sjå dataa.

- Steg 4 bør berre brukast med ekte brukarar når ein vaksen står som
  ansvarleg. I kurset held det å byggje med testbrukarar og oppdikta data.

- Steg 5 viser kvifor «det verkar» ikkje betyr «det er trygt». Mange av dei
  kjende historiene om appar som vart hacka etter ei veke, handlar om dette.

### Kva er testa

Oppgåva er skriven i november 2026 og er ikkje prøvd med elevar enno.
