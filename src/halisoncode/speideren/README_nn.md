# Om oppgåva {.activity}

Elevane ser gjennom robotkameraet, lèt roboten flyge og brukar sensorane biom,
tel i nærleiken og lysnivå. Svara blir lagra i ein variabel, og roboten vel kva
han skal seie med viss og elles.

## Oppgåva passar til: {.check}

__Fag__: Programmering, teknologi

__Tilrådde trinn__: 5. til 10. trinn

__Tema__: Sensorar, variablar, viss og elles, Minecraft

__Nivå__: 1

__Tidsbruk__: Omtrent ein time.

## Kompetansemål {.challenge}

- [ ] __Matematikk, 5. trinn__: lage og programmere algoritmar med bruk av
  variablar, vilkår og lykkjer

- [ ] __Programmering, 8.-10. trinn__: bruke grunnleggende prinsipper i
  programmering, slik som variabler, løkker, vilkår og funksjoner, og reflektere
  over bruken av disse

## Forslag til læringsmål {.challenge}

- [ ] Elevane kan bruke robotkameraet.

- [ ] Elevane kan lagre eit måleresultat i ein variabel.

- [ ] Elevane kan bruke viss og elles til å velje mellom to handlingar.

## Forslag til vurderingskriterium {.challenge}

- [ ] Eleven oppnår middels måloppnåing ved å få roboten til å flyge, lande og
  seie kva biom han er i.

- [ ] Eleven oppnår høg måloppnåing ved å la roboten melde frå om både dyr og
  mørker, og forklare kva variabelen inneheld.

## Føresetnader og utstyr {.challenge}

- [ ] __Føresetnader__: Dei tidlegare oppgåvene i kurset.

- [ ] __Utstyr__: Halison Code installert, Minecraft Java Edition og ein
  nettlesar. Sjå oppgåva Installere Halison Code.


# Framgangsmåte {.activity}

## Før timen {.check}

- [ ] Prøv oppgåva sjølv i same Minecraft-versjon som elevane brukar.

## Steg 1: Kamera {.check}

- [ ] Kameraet kan vere slått av på ein server. Då stoppar programmet med ein
  feil. I ei einspelarverd verkar det.

## Steg 3 og 4: Sensorar {.check}

- [ ] Biomet kjem på engelsk, til dømes `plains`. Det er namnet spelet brukar.

- [ ] Seier roboten fleire ting rett etter kvarandre, kan det første forsvinne
  fort. Ein `pause (ms)` mellom hjelper.

## Vanlege problem {.protip}

- Programma er borte: dei blir lagra i nettlesaren på maskina eleven brukte.
  Opne editoren i same nettlesar, eller hent inn `.mkcd`-fila eleven lagra med
  `Hent inn` på startsida. På maskiner som blir nullstilte, må elevane lagre
  prosjektet som fil før timen er slutt.

- Roboten står stille etter at eleven bytte vindauge: Minecraft er på pause.
  Trykk `Attende til spelet`. `F3` + `P` slår av pause når vindauget mistar
  fokus, og `/gamerule halisoncode:pause_on_lost_focus false` gjer det for heile
  verda.

- Chatkommandoen verkar ikkje: programmet må køyre og editoren stå open. Trykk
  `Kjør` i editoren før eleven byter til Minecraft.

- Roboten flyg inn i eit fjell og stoppar: `flytt` stoppar ved første blokk.
  Fly høgare.

- Ingen dyr blir funne: radiusen er høgst 8 blokker. Fly nærare.
