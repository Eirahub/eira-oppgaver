# Om oppgaven {.activity}

Elevene ser gjennom robotkameraet, lar roboten fly og bruker sensorene biom,
tell i nærheten og lysnivå. Svarene lagres i en variabel, og roboten velger hva
den skal si med hvis og ellers.

## Oppgaven passer til: {.check}

__Fag__: Programmering, teknologi

__Anbefalte trinn__: 5. til 10. trinn

__Tema__: Sensorer, variabler, hvis og ellers, Minecraft

__Nivå__: 1

__Tidsbruk__: Omtrent en time.

## Kompetansemål {.challenge}

- [ ] __Matematikk, 5. trinn__: lage og programmere algoritmer med bruk av
  variabler, vilkår og løkker

- [ ] __Programmering, 8.-10. trinn__: bruke grunnleggende prinsipper i
  programmering, slik som variabler, løkker, vilkår og funksjoner, og
  reflektere over bruken av disse

## Forslag til læringsmål {.challenge}

- [ ] Elevene kan bruke robotkameraet.

- [ ] Elevene kan lagre et måleresultat i en variabel.

- [ ] Elevene kan bruke hvis og ellers til å velge mellom to handlinger.

## Forslag til vurderingskriterier {.challenge}

- [ ] Eleven oppnår middels måloppnåelse ved å få roboten til å fly, lande og si
  hvilket biom den er i.

- [ ] Eleven oppnår høy måloppnåelse ved å la roboten melde fra om både dyr og
  mørke, og forklare hva variabelen inneholder.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: De tidligere oppgavene i kurset.

- [ ] __Utstyr__: Halison Code installert, Minecraft Java Edition og en
  nettleser. Se oppgaven Installere Halison Code.


# Fremgangsmåte {.activity}

## Før timen {.check}

- [ ] Prøv oppgaven selv i samme Minecraft-versjon som elevene bruker.

## Steg 1: Kamera {.check}

- [ ] Kameraet kan være slått av på en server. Da stopper programmet med en
  feil. I en enspillerverden virker det.

## Steg 3 og 4: Sensorer {.check}

- [ ] Biomet kommer på engelsk, for eksempel `plains`. Det er navnet spillet
  bruker.

- [ ] Sier roboten flere ting rett etter hverandre, kan det første forsvinne
  fort. En `pause (ms)` mellom hjelper.

## Vanlige problemer {.protip}

- Roboten flyr inn i et fjell og stopper: `flytt` stopper ved første blokk. Fly
  høyere.

- Ingen dyr blir funnet: radiusen er høyst 8 blokker. Fly nærmere.
