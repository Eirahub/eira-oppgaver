Halison Code er en mod til Minecraft Java Edition som gir deg en liten robot,
Kintro, i verdenen din. Du programmerer roboten i nettleseren med blokker, JavaScript
eller Python, i en editor som ligner MakeCode. Hver kommando du kjører, får
roboten til å gjøre noe i spillet: gå, bygge, grave, hogge trær og fylle kister.

Oppgavene krever ingen forkunnskaper i programmering. Det hjelper å ha spilt
litt Minecraft før.

## Hvordan komme i gang

- En voksen må installere Minecraft Java Edition, en modlaster og
  Halison Code på datamaskinen. [Her er installasjonen steg for
  steg](installasjon/installasjon.html). Det tar omtrent ti minutter.

- Start en verden, skriv `/robot spawn` i chatten for å lage roboten, og
  `/halisoncode` for å åpne editoren i nettleseren.

- Begynn med oppgaven `Kom i gang`. Oppgavene blir vanskeligere etter hvert,
  og de siste bruker JavaScript eller Python.
