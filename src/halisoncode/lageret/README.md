# Om oppgaven {.activity}

Elevene går over til JavaScript. Roboten lager planker av stammer så lenge det
går, setter ut en arbeidsbenk for å lage en kiste, og legger alt i kista og
sorterer den.

## Oppgaven passer til: {.check}

__Fag__: Programmering, teknologi

__Anbefalte trinn__: 8. til 10. trinn

__Tema__: JavaScript, inventar, oppskrifter, beholdere

__Nivå__: 3

__Tidsbruk__: En til to timer.

## Kompetansemål {.challenge}

- [ ] __Programmering, 8.-10. trinn__: bruke grunnleggende prinsipper i
  programmering, slik som variabler, løkker, vilkår og funksjoner, og
  reflektere over bruken av disse

- [ ] __Programmering, 8.-10. trinn__: bruke flere programmeringsspråk,
  deriblant minst ett som er tekstbasert

## Forslag til læringsmål {.challenge}

- [ ] Elevene kan skrive og kjøre et enkelt program i JavaScript.

- [ ] Elevene kan bruke `while` med en betingelse som sjekker om noe er mulig.

- [ ] Elevene kan forklare hva en plass i inventaret er.

## Forslag til vurderingskriterier {.challenge}

- [ ] Eleven oppnår middels måloppnåelse ved å lage planker av alle stammene og
  legge dem i en kiste.

- [ ] Eleven oppnår høy måloppnåelse ved å lage funksjonen `ryddLager` med
  chatkommando, og forklare hvorfor en kiste trenger arbeidsbenk.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: De tidligere oppgavene i kurset.

- [ ] __Utstyr__: Halison Code installert, Minecraft Java Edition og en
  nettleser. Se oppgaven Installere Halison Code.


# Fremgangsmåte {.activity}

## Før timen {.check}

- [ ] Prøv oppgaven selv i samme Minecraft-versjon som elevene bruker.

## Steg 1: JavaScript {.check}

- [ ] Vis at blokkene og JavaScript er samme program. Elevene kan bytte frem og
  tilbake.

## Steg 3: Arbeidsbenk {.check}

- [ ] `robot gi` virker bare i Kreativ. I overlevelse må roboten lage
  arbeidsbenken selv av fire planker.

## Vanlige problemer {.protip}

- Skrivefeil i JavaScript: editoren streker under feilen. Store og små bokstaver
  teller.

- Kista er full: en kiste har 27 plasser.
