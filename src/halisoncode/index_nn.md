Halison Code er ein mod til Minecraft Java Edition som gir deg ein liten robot,
Kintro, i verda di. Du programmerer roboten i nettlesaren med blokker,
JavaScript eller Python, i ein editor som liknar MakeCode. Kvar kommando du
køyrer, får roboten til å gjere noko i spelet: gå, byggje, grave, hogge tre og
fylle kister.

Oppgåvene krev ingen forkunnskapar i programmering. Det hjelper å ha spelt
litt Minecraft før.

## Korleis kome i gang

- Ein vaksen må installere Minecraft Java Edition, ein modlastar og
  Halison Code på datamaskina. [Her er installasjonen steg for
  steg](installasjon/installasjon_nn.html). Det tek omtrent ti minutt.

- Start ei verd, skriv `/robot spawn` i chatten for å lage roboten, og
  `/halisoncode` for å opne editoren i nettlesaren.

- Byrj med oppgåva `Kom i gang`. Oppgåvene blir vanskelegare etter kvart,
  og dei siste bruker JavaScript eller Python.

## Ressursar

MakeCode-teamet. Minecraft er eit varemerke som høyrer til Mojang Synergies AB.

gjeld oppgåvetekstane. Skjermbileta blir brukte etter retningslinjene til
