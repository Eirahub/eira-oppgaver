# Om oppgåva {.activity}

Elevane byggjer ei hol glaskule, ein ring av faklar og strålar av glødestein
med klossane i kategorien Former. Til slutt spreier dei fargerike kuler på
tilfeldige stader med ei lykkje og `velg tilfeldig posisjon`.

## Oppgåva passar til: {.check}

__Fag__: Programmering, teknologi

__Tilrådde trinn__: 5. til 10. trinn

__Tema__: Former, posisjonar, lykkjer, tilfeldigheit

__Nivå__: 1

__Tidsbruk__: Omtrent ein time.

## Kompetansemål {.challenge}

- [ ] __Matematikk, 5. trinn__: lage og programmere algoritmar med bruk av
  variablar, vilkår og lykkjer

- [ ] __Matematikk, 6. trinn__: bruke variablar, lykkjer, vilkår og funksjonar
  i programmering til å utforske geometriske figurar og mønster

- [ ] __Programmering, 8.-10. trinn__: bruke grunnleggende prinsipper i
  programmering, slik som variabler, løkker, vilkår og funksjoner, og reflektere
  over bruken av disse

## Forslag til læringsmål {.challenge}

- [ ] Elevane kan beskrive ei kule og ein sirkel med sentrum og radius.

- [ ] Elevane kan bruke ei lykkje til å gjenta ein del av programmet.

- [ ] Elevane kan forklare kva ein tilfeldig posisjon i ein boks er.

## Forslag til vurderingskriterium {.challenge}

- [ ] Eleven oppnår middels måloppnåing ved å byggje kula, ringen og strålane.

- [ ] Eleven oppnår høg måloppnåing ved å spreie tilfeldige kuler med ei lykkje
  og forklare kvifor resultatet blir ulikt kvar gong.

## Føresetnader og utstyr {.challenge}

- [ ] __Føresetnader__: Oppgåva Kom i gang.

- [ ] __Utstyr__: Halison Code installert, Minecraft Java Edition og ein
  nettlesar. Sjå oppgåva Installere Halison Code.


# Framgangsmåte {.activity}

## Før timen {.check}

- [ ] Prøv oppgåva sjølv i same Minecraft-versjon som elevane brukar.

## Steg 1 til 3: Former {.check}

- [ ] `~` er målt frå spelaren. Flyttar eleven seg, hamnar forma ein annan
  stad.

- [ ] Alle formene må vere innanfor 32 blokker frå roboten. Koordinatane i
  oppgåva held seg innanfor viss eleven står nær roboten.

- [ ] `rundt y` legg ringen flatt. `rundt x` og `rundt z` reiser han opp.

## Steg 4: Tilfeldige kuler {.check}

- [ ] Kvar kule får sin eigen tilfeldige posisjon, så dei tre kulene i lykkja
  hamnar på ulike stader. Kuler kan overlappe.

## Vanlege problem {.protip}

- Programma er borte: dei blir lagra i nettlesaren på maskina eleven brukte.
  Opne editoren i same nettlesar, eller hent inn `.mkcd`-fila eleven lagra med
  `Hent inn` på startsida. På maskiner som blir nullstilte, må elevane lagre
  prosjektet som fil før timen er slutt.

- Roboten står stille etter at eleven bytte vindauge: Minecraft er på pause.
  Trykk `Attende til spelet`. `F3` + `P` slår av pause når vindauget mistar
  fokus, og `/gamerule halisoncode:pause_on_lost_focus false` gjer det for heile
  verda.

- Ingenting blir bygd: roboten er for langt unna. Skriv `/robot spawn`.

- Området blir fullt av gamle forsøk: rydd med `fyll med luft`, eller bygg på
  ein ny stad.
