Visual Studio Code, ofte kalt **VS Code**, er et gratis program for å skrive
kode. Det finnes for Windows, Mac og Linux, og du kan bruke det til Python,
nettsider, Java og nesten alle andre språk. Mange som jobber med programmering,
bruker det hver dag.

I dette kurset installerer du VS Code og lærer de delene du trenger i
kodeklubben: filer og mapper, terminalen, å kjøre Python, å finne feil med
debuggeren, å lagre arbeidet ditt med Git og å velge trygge utvidelser.

Kurset passer fra 8. trinn og oppover, og for veiledere i kodeklubben som vil
bli trygge på verktøyet før de hjelper andre.

## Hvordan komme i gang

- Begynn med [Installer VS Code](installer_vs_code/installer_vs_code.html). På
  skolemaskiner trenger du kanskje hjelp fra en voksen.

- Ta så [Bli kjent med VS Code](bli_kjent/bli_kjent.html). Etter det kan du
  velge Python, nettsider eller Git i den rekkefølgen du vil.

- Velg filteret **Oppgavesamlinger** for å se alle oppgavene i rekkefølge.

VS Code er laget av Microsoft. Kurset er ikke laget av eller godkjent av
Microsoft. Visual Studio Code er et varemerke som tilhører Microsoft.
