# Om oppgaven {.activity}

Elevene åpner en prosjektmappe og lærer Explorer, Auto Save, kommandopaletten,
terminalen, zoom og noen snarveier. Mappa `kodeklubb` brukes videre i resten av
kurset.

## Oppgaven passer til: {.check}

__Fag__: Programmering, IT1, IT2

__Anbefalte trinn__: 8. trinn til VG3, og veiledere

__Tema__: Verktøy, filer og mapper, terminal

__Nivå__: 1 (introduksjon)

__Tidsbruk__: 30 til 45 minutter

- [ ] Eleven kan åpne terminalen og bruke `ls` og `cd`.

# Steg 1: Åpne en mappe {.activity}

- [ ] Workspace Trust spør om man stoler på forfatterne når en mappe åpnes
  første gang. **No, I don't trust the authors** gir *Restricted Mode*, der
  terminal, debugging og mange utvidelser er slått av. Velger eleven feil, kan
  det rettes med lenken i banneret øverst. Kilde: [Workspace
  Trust](https://code.visualstudio.com/docs/editing/workspaces/workspace-trust).

- [ ] Elever som åpner en enkeltfil med **Open File...**, får problemer senere
  med Python (terminalen starter i feil mappe) og med Git.


# Steg 3: Lagre automatisk {.activity}

- [ ] **Auto Save** lagrer etter 1 sekund som standard (`files.autoSaveDelay`).
  Kilde: [Basic editing](https://code.visualstudio.com/docs/editing/codebasics).


# Steg 5: Terminalen {.activity}

- [ ] På Windows er terminalen vanligvis PowerShell, på Mac zsh og på Linux
  bash. `ls`, `cd` og `cd ..` virker i alle tre.

- [ ] Snarveien **Ctrl** + **`** er laget for amerikansk tastatur. På norsk
  tastatur er tasten et dødt tegn, og snarveien kan bli en annen. Oppgaven
  bruker derfor menyene **Terminal** > **New Terminal** og **View** >
  **Terminal**. Kilde: [Terminal
  basics](https://code.visualstudio.com/docs/terminal/basics).


# Steg 6: Zoom og snarveier {.activity}

- [ ] Standardsnarveiene for zoom er **Ctrl** + **=** og **Ctrl** + **-**, i
  tillegg til **Ctrl** med **+** og **-** på talltastaturet. Menyen **View** >
  **Appearance** virker alltid.

- [ ] Skriv ut snarveiene for elevene:
  [Windows](https://go.microsoft.com/fwlink/?linkid=832145),
  [macOS](https://go.microsoft.com/fwlink/?linkid=832143) og
  [Linux](https://go.microsoft.com/fwlink/?linkid=832144) (PDF, amerikansk
  tastatur).
