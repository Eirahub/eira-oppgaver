# Om oppgaven {.activity}

En kort oppgave som viser at VS Code også brukes til nettsider: Emmet, Live
Preview og en CSS-fil. Den fulle versjonen er [Lag nettsider i VS
Code](../../web/vs_code/vs_code.html) i Web-kurset, med egen lærerveiledning.

__Anbefalte trinn__: 8. trinn til VG3, og veiledere

__Tema__: HTML, CSS, verktøy

__Nivå__: 1 (introduksjon)

__Tidsbruk__: 20 minutter

# Steg 2: Live Preview {.activity}

- [ ] Utvidelsen heter **Live Preview**, har ID `ms-vscode.live-server` og
  publisher **Microsoft**. Forhåndsvisningen åpnes med knappen øverst til høyre
  eller fra høyreklikkmenyen. Kilde: [Live Preview på Visual Studio
  Marketplace](https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server).

- [ ] Ikke bland den med den eldre utvidelsen *Live Server* fra en annen
  publisher. Oppgavene bruker Live Preview fra Microsoft.

- [ ] Kan elevene ikke installere utvidelser, kan de dobbeltklikke på
  `index.html` og laste siden på nytt i nettleseren etter hver lagring.
