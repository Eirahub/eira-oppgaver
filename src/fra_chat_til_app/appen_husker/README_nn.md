# Om oppgåva {.activity}

Eleven får appen til å hugse data mellom kvar gong han blir opna, lagar ein
knapp som slettar alt, lagar tryggleikskopi og vurderer kva
personopplysningar appen ikkje bør lagre.

## Oppgåva passar til: {.check}

__Fag__: Programmering, informasjonsteknologi

__Tilrådde trinn__: 8. trinn til vidaregåande

__Tema__: Datalagring, tryggleikskopi, personvern

__Tidsbruk__: 60 minutt

## Kompetansemål {.challenge}

- [ ] __Informasjonsteknologi 1__: lagre og hente fram data, presentere data på
  nettsider og reflektere over hvordan representasjonsform kan påvirke
  tolkningen

- [ ] __Informasjonsteknologi 1__: gjøre rede for gjeldende personvernregelverk
  og hvilke konsekvenser det har for utvikling av informasjonsteknologi

- [ ] __Programmering, 10. trinn__: utvikle og feilsøke dataprogram som løser
  definerte problemer, inkludert kontrollering eller simulering av fysiske
  objekter

## Forslag til vurderingskriterium {.challenge}

Appen hugsar data etter omstart og har eksport og import. Eleven kan forklare
kvar dataa ligg, kven som kan sjå dei, og kvifor appen ikkje lagrar meir enn
han treng.

## Føresetnader og utstyr {.challenge}

- [ ] __Føresetnader__: [Gjer appen betre](../forbedre_appen/forbedre_appen_nn).

- [ ] __Utstyr__: PC med KIT Apps og tilgang til ein KI-chat.

## Framgangsmåte

### Tips til rettleiarar

- Dataa ligg lokalt på PC-en. På skule-PC-ar som blir nullstilte, kan dei
  forsvinne. Det er ein fin sjanse til å snakke om tryggleikskopi.

- Deling via ei delt mappe er berre nemnt. Bruk det ikkje med
  personopplysningar om elevar.

### Kva er testa

Promptane er testa på bokmål med Claude Haiku og Claude Sonnet i november
2026, og appane starta utan feil i KIT Apps. Oppgåva er ikkje prøvd med elevar
enno.
