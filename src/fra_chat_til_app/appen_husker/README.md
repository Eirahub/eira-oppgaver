# Om oppgaven {.activity}

Eleven får appen til å huske data mellom hver gang den åpnes, lager en knapp som
sletter alt, lager sikkerhetskopi og vurderer hvilke personopplysninger appen
ikke bør lagre.

## Oppgaven passer til: {.check}

__Fag__: Programmering, informasjonsteknologi

__Anbefalte trinn__: 8. trinn til videregående

__Tema__: Datalagring, sikkerhetskopi, personvern

__Tidsbruk__: 60 minutter

## Kompetansemål {.challenge}

- [ ] __Informasjonsteknologi 1__: lagre og hente fram data, presentere data på
  nettsider og reflektere over hvordan representasjonsform kan påvirke
  tolkningen

- [ ] __Informasjonsteknologi 1__: gjøre rede for gjeldende personvernregelverk
  og hvilke konsekvenser det har for utvikling av informasjonsteknologi

- [ ] __Programmering, 10. trinn__: utvikle og feilsøke dataprogram som løser
  definerte problemer, inkludert kontrollering eller simulering av fysiske
  objekter

## Forslag til vurderingskriterier {.challenge}

Appen husker data etter omstart og har eksport og import. Eleven kan forklare
hvor dataene ligger, hvem som kan se dem, og hvorfor appen ikke lagrer mer enn
den trenger.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: [Gjør appen bedre](../forbedre_appen/forbedre_appen).

- [ ] __Utstyr__: PC med KIT Apps og tilgang til en KI-chat.

### Tips til veiledere

- Dataene ligger lokalt på PC-en. På skole-PC-er som nullstilles, kan de
  forsvinne. Det er en fin anledning til å snakke om sikkerhetskopi.

- Deling via en delt mappe er bare nevnt. Bruk det ikke med personopplysninger
  om elever.

### Hva er testet

Promptene er kjørt med Claude Haiku og Claude Sonnet i november 2026, og
appene startet uten feil i KIT Apps. Oppgaven er ikke prøvd med elever ennå.
