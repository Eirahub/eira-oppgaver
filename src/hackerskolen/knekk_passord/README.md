# Om oppgaven {.activity}

Eleven lærer hva en hash er, skriver et ordlisteangrep i Python mot en oppdiktet
lekket database, regner på hvor lang tid det tar å prøve alle passord og lærer
hva salt gjør.

## Oppgaven passer til: {.check}

__Fag__: Programmering, informasjonsteknologi, matematikk

__Anbefalte trinn__: 8. trinn til videregående

__Tema__: Hashfunksjoner, passord, kombinatorikk

__Tidsbruk__: 60 til 90 minutter

## Kompetansemål {.challenge}

- [ ] __Programmering, 10. trinn__: bruke grunnleggende prinsipper i
  programmering, slik som variabler, løkker, vilkår og funksjoner, og reflektere
  over bruken av disse

- [ ] __Informasjonsteknologi 2__: gjøre rede for standarder for lagring,
  utveksling og sikring av ulike typer data

- [ ] __Informasjonsteknologi 1__: drøfte problemstillinger knyttet til
  innhenting, bruk og misbruk av data

## Forslag til vurderingskriterier {.challenge}

Eleven har knekt passordet til sjefen og kan forklare med regning hvorfor lange
passord er sterkere enn korte med mange tegn.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: [Sett opp laben](../sett_opp_laben/sett_opp_laben).
  Litt Python: variabler, løkker og `if`.

- [ ] __Utstyr__: PC med laben og Python 3.

### Tips til veiledere

- Passordene i databasen er oppdiktet. Be elevene aldri bruke ekte passord i
  oppgaven.

- Steg 3 passer godt sammen med potenser og kombinatorikk i matematikk.

- [Hash-funksjoner](../../python/hash-funksjoner/hash-funksjoner) og
  [Passordlagring](../../python/passordlagring/passordlagring) går dypere i det
  samme.

### Hva er testet

Laben og alle kommandoene i oppgaven er kjørt på Linux med Python 3.12 i
november 2026. Oppgaven er ikke prøvd på Windows og Mac, eller med elever, ennå.
