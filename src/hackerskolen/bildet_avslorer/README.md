# Om oppgaven {.activity}

Eleven leser GPS-posisjonen i metadataene til et oppdiktet feriebilde, finner
stedet og ser på metadataene i egne bilder.

## Oppgaven passer til: {.check}

__Fag__: Informasjonsteknologi, samfunnsfag

__Anbefalte trinn__: 8. trinn til videregående

__Tema__: Metadata, OSINT, personvern

__Tidsbruk__: 30 til 45 minutter

## Kompetansemål {.challenge}

- [ ] __Samfunnsfag, 10. trinn__: utforske og reflektere over egne digitale spor
  og muligheten for å få slettet sporene og verne om egen og andres rett til
  privatliv, personvern og opphavsrett

- [ ] __Informasjonsteknologi 1__: drøfte problemstillinger knyttet til
  innhenting, bruk og misbruk av data

## Forslag til vurderingskriterier {.challenge}

Eleven har funnet stedet og kan nevne tre ting de selv gjør for å ikke avsløre
hvor de bor.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: Ingen. Laben er fin å ha, men bildet kan lastes ned
  fra oppgaven.

- [ ] __Utstyr__: PC og gjerne en mobil med kamera.

## Fremgangsmåte

[Klikk her for å se oppgaveteksten.](bildet_avslorer)

### Tips til veiledere

- Bildet er tegnet for kurset, og koordinatene peker på Preikestolen.

- Pass på at elevene bare ser på egne bilder, eller bilder de har fått lov til å
  bruke.

- Oppgaven passer godt sammen med samtaler om deling på sosiale medier.

### Hva er testet

Laben og alle kommandoene i oppgaven er kjørt på Linux med Python 3.12 i
november 2026. Oppgaven er ikke prøvd på Windows og Mac, eller med elever, ennå.
