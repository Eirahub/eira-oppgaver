# Om oppgaven {.activity}

Eleven lærer de vanligste kommandoene i terminalen, finner en skjult mappe og
søker i en stor fil med `grep`.

## Oppgaven passer til: {.check}

__Fag__: Programmering, informasjonsteknologi

__Anbefalte trinn__: 8. trinn til videregående

__Tema__: Kommandolinje, filer og mapper, søk

__Tidsbruk__: 45 minutter

## Kompetansemål {.challenge}

- [ ] __Programmering, 10. trinn__: gjøre rede for hvordan datamaskiner og
  dataprogram fungerer, og forklare egne og andres koder

- [ ] __Informasjonsteknologi 1__: beskrive sentrale komponenter i datamaskiner
  og nettverk og gjøre rede for hvilken funksjon de har

## Forslag til vurderingskriterier {.challenge}

Eleven har funnet to flagg og kan bruke `ls -a`, `cd`, `cat` og `grep` uten å se
på juksearket.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: [Sett opp laben](../sett_opp_laben/sett_opp_laben).

- [ ] __Utstyr__: PC med laben og en bash-terminal.

## Fremgangsmåte

### Tips til veiledere

- Mange elever har aldri brukt en terminal. Vis Tab og pil opp tidlig. Det
  sparer mye frustrasjon.

- Linux Journey og de andre oppgavene i [Kommandolinje](../../command_line/)
  passer som ekstra trening.

### Hva er testet

Laben og alle kommandoene i oppgaven er kjørt på Linux med Python 3.12 i
november 2026. Oppgaven er ikke prøvd på Windows og Mac, eller med elever, ennå.
