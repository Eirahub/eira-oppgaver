# Om oppgaven {.activity}

Elevene lager en robot i Minecraft, åpner Codeling-editoren i nettleseren og
skriver sitt første program med blokker. De får roboten til å gå, snu seg og si
hei, og går i en firkant. Til slutt ser de det samme programmet som
JavaScript. Oppgaven introduserer sekvens, rekkefølge og feilsøking.

## Oppgaven passer til: {.check}

__Fag__: Programmering, teknologi

__Anbefalte trinn__: 5. til 10. trinn

__Tema__: Blokkbasert programmering, sekvens, Minecraft

__Nivå__: 1

__Tidsbruk__: Omtrent en time. Dobbelttime hvis elevene tar utfordringene.

## Kompetansemål {.challenge}

- [ ] __Matematikk, 5. trinn__: lage og programmere algoritmer med bruk av
  variabler, vilkår og løkker

- [ ] __Programmering, 8.-10. trinn__: utvikle og feilsøke dataprogram som løser
  definerte problemer, inkludert kontrollering eller simulering av fysiske
  objekter

## Forslag til læringsmål {.challenge}

- [ ] Elevene kan lage en robot og åpne editoren.

- [ ] Elevene kan sette sammen blokker i riktig rekkefølge så roboten gjør det
  de vil.

- [ ] Elevene kan forklare at et program kjøres én kommando av gangen,
  ovenfra og ned.

- [ ] Elevene kan feilsøke et program ved å endre tall og rekkefølge.

- [ ] Elevene kan peke på at blokkene og JavaScript-koden gjør det samme.

## Forslag til vurderingskriterier {.challenge}

- [ ] Eleven oppnår middels måloppnåelse ved å få roboten til å gå, snu og si
  `Hei!`.

- [ ] Eleven oppnår høy måloppnåelse ved å få roboten til å gå i en firkant og
  tilbake til startpunktet, og forklare hva som skjer hvis rekkefølgen byttes.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: Ingen forkunnskaper i programmering. Det hjelper å ha
  spilt litt Minecraft.

- [ ] __Installasjon__: Codeling må være installert før timen, se oppgaven
  Installere Codeling. Minecraft Java Edition og en modlaster som Fabric eller
  NeoForge er påkrevd.

- [ ] __Maskiner__: Windows, macOS eller Linux. Nettbrett og mobil fungerer
  ikke.
  Elevene trenger både Minecraft og en nettleser åpen samtidig, så en maskin med
  nok minne og to vinduer side om side er best.

- [ ] __Nett__: Nettleseren åpner editoren lokalt fra Minecraft. Sjekk at
  nettverket ikke blokkerer det.

- [ ] __Konto__: Minecraft Java Edition må eies. Planlegg for elever uten
  spillet, for eksempel som makkerpar.


# Fremgangsmåte {.activity}

## Før timen {.check}

- [ ] Prøv oppgaven selv i en verden i Kreativ og Flat, så du kjenner til
  hvordan roboten oppfører seg.

- [ ] Be elevene lage verden selv, så de har noe å eie. En flat verden gjør det
  lett å se hva roboten gjør.

## Steg 1: Lag roboten {.check}

- [ ] Elevene skriver `/robot spawn` i chatten. Skriver de det igjen, flyttes
  roboten til dem. Det er nyttig hvis den har gått bort.

- [ ] Kommer ikke roboten, sjekk at de er i en verden og at modden er lastet.

## Steg 2: Editoren {.check}

- [ ] `/codeling` åpner nettleseren. Lenken virker bare på denne maskinen og
  bare mens Minecraft kjører.

- [ ] Hjelp elevene å plassere vinduene side om side. Pausemenyen i Minecraft
  pauser spillet, og roboten venter til menyen lukkes.

## Steg 3 og 4: Gå, snu og si {.check}

- [ ] Kategorien Robot er grønn. Bruk navnene i oppgaven når du hjelper.

- [ ] Elever bruker ofte feil retning. Retningene er sett fra roboten, ikke fra
  spilleren.

- [ ] Elever drar blokker ved siden av `ved start`. Da kjører ingenting. Se at
  alle blokkene er festet i en kjede.

- [ ] Be elevene gjette hva som skjer før de trykker Kjør.

## Steg 5: Firkant {.check}

- [ ] Bruk firkanten som fortsettelse. Mange gjentar de samme blokkene fire
  ganger, og da kommer ideen om løkker i neste oppgave.

- [ ] Roboten ender ikke alltid der den startet hvis eleven bruker ulike tall
  eller snur feil vei. La dem sammenligne.

## Vanlige problemer {.protip}

- Roboten står stille: spillet kan være pauset, eller blokkene er ikke koblet
  til `ved start`.

- Roboten er langt unna: `/robot spawn` flytter den til eleven.

- Programmet kjører og eleven vil avbryte: stoppknappen i editoren eller
  `/robot stop` i chatten.


# Variasjoner {.activity}

- La elevene bytte datamaskiner og lese hverandres programmer.

- La elevene skrive programmet som tekst i JavaScript og sammenligne med
  blokkene.

- La elevene gi hverandre oppdrag, som å tegne bokstaven L med roboten.
