# Om oppgaven {.activity}

Eleven lager en enkel HTML-side, publiserer repoet og slår på GitHub Pages, slik
at siden får en adresse alle kan åpne. Til slutt oppdaterer eleven siden og ser
den bygges på nytt.

## Oppgaven passer til: {.check}

__Fag__: Programmering, informasjonsteknologi

__Anbefalte trinn__: 8. trinn til videregående

__Tema__: Nettsider, publisering, GitHub Pages

__Tidsbruk__: 30 til 45 minutter

## Kompetansemål {.challenge}

- [ ] __Programmering, 10. trinn__: planlegge og skape et digitalt produkt og
  vurdere dette med tanke på brukervennlighet

- [ ] __Informasjonsteknologi 1, Vg2__: utvikle nettsider ved hjelp av
  markeringsspråk

- [ ] __Informasjonsteknologi 1, Vg2__: drøfte problemstillinger knyttet til
  innhenting, bruk og misbruk av data

## Forslag til vurderingskriterier {.challenge}

Eleven har en side som er publisert på GitHub Pages og har oppdatert den med en
ny commit. Eleven kan forklare hva som skjer fra commit til ny versjon av siden,
og hva som ikke bør stå på en offentlig side.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: [Del koden på GitHub](../del_pa_github/del_pa_github).
  Gjerne litt HTML fra [Web-kurset](../../web/).

- [ ] __Utstyr__: PC med VS Code og Git, en nettleser og en GitHub-konto per

## Fremgangsmåte

[Klikk her for å se oppgaveteksten.](github_pages)

### Tips til veiledere

- Med gratis konto virker GitHub Pages bare for public repoer. Alt i repoet og
  på siden kan leses av alle. Gå gjennom hva som ikke skal på siden før elevene
  publiserer.

- Første gang kan det ta et par minutter før siden er klar. Fanen **Actions**
  viser når den er bygget.

- Adressen blir `brukernavn.github.io/repo`. Brukernavnet er altså synlig i
  adressen. Det er et argument for brukernavn som ikke er fullt navn.

### Hva er testet

Stegene og skjermbildene er laget med VS Code og github.com i november 2026.
Oppgaven er ikke prøvd med elever ennå.
