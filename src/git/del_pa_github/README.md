# Om oppgaven {.activity}

Eleven skriver en README, holder filer utenfor Git med `.gitignore`, publiserer
repoet på GitHub, henter en endring gjort på github.com og kloner prosjektet til
en ny mappe.

## Oppgaven passer til: {.check}

__Fag__: Programmering, informasjonsteknologi

__Anbefalte trinn__: 8. trinn til videregående

__Tema__: README og Markdown, .gitignore, push, pull og clone

__Tidsbruk__: 45 til 60 minutter

## Kompetansemål {.challenge}

- [ ] __Informasjonsteknologi 2, Vg3__: velge og bruke relevante
  systemutviklingsmetoder og -verktøy for samarbeid med andre

- [ ] __Informasjonsteknologi 1, Vg2__: utforske, strukturere og kommentere
  programkode

- [ ] __Informasjonsteknologi 1, Vg2__: drøfte problemstillinger knyttet til
  innhenting, bruk og misbruk av data

## Forslag til vurderingskriterier {.challenge}

Eleven har et repo på GitHub med README og `.gitignore`, kan forklare push og
pull, og kan si hvorfor hemmeligheter aldri skal inn i et repo.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: [Prøv en idé på en gren](../grener/grener). Steg 5 i
  [Git i VS Code](../../vs_code/git_i_vs_code/git_i_vs_code) for innlogging på
  GitHub fra VS Code.

- [ ] __Utstyr__: PC med VS Code og Git, og en GitHub-konto per elev.

### Tips til veiledere

- GitHub krever at brukeren er 13 år eller eldre. Yngre elever kan gjøre
  oppgaven sammen med en voksen som har konto, eller stoppe etter steg 2.

- Lag kontoene før timen. Bekreftelse av e-post og tofaktorinnlogging tar tid.

- E-postadressen i commitene blir synlig når repoet er public. På GitHub kan
  eleven velge **Keep my email addresses private** under **Settings** og
  **Emails**, og bruke noreply-adressen GitHub gir, med `git config --global
  user.email`.

- Det som først er pushet, kan bli liggende. Snakk om hva som ikke hører hjemme
  i et public repo: passord, navn, adresser og bilder av folk.

### Hva er testet

Stegene og skjermbildene er laget med VS Code og github.com i november 2026.
Oppgaven er ikke prøvd med elever ennå.
