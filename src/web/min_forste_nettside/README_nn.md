# Om oppgåva {.activity}

Elevane lagar ei nettside om noko dei likar. Undervegs brukar dei dei viktigaste
HTML-taggane: overskrifter, avsnitt, lister, bilete og lenkjer. Til slutt gir
dei sida stil med CSS. Oppgåva legg vekt på alt-tekst på bilete og gode
lenkjetekstar, slik at sida også fungerer for dei som brukar skjermlesar.

## Oppgåva passar til: {.check}

__Fag__: Programmering, Norsk, Kunst og handverk, IT1

__Tilrådde trinn__: 5. trinn til VG3

__Tema__: HTML, CSS, Web, Universell utforming

__Nivå__: 1 (nybyrjar)

__Tidsbruk__: Dobbeltime

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan bruke overskrifter på fleire nivå for å gi sida struktur.

- [ ] Eleven kan lage punktlister og nummererte lister.

- [ ] Eleven kan setje inn eit bilete med ein skildrande alt-tekst og forklare
  kvifor alt-tekst er viktig.

- [ ] Eleven kan lage ei lenkje med ein lenkjetekst som seier kvar ho går.

- [ ] Eleven kan endre fargar, skrift og plassering med enkle CSS-reglar.

## Forslag til vurderingskriterium {.challenge}

- [ ] Eleven oppnår middels måloppnåing ved å fullføre oppgåva med sitt eige
  tema.

- [ ] Eleven oppnår høg måloppnåing ved å lage ei side med god struktur, gode
  alt-tekstar og lenkjetekstar, og ved å løyse utfordringane.

# Steg 1: Vel eit tema {.activity}

- [ ] La elevane bestemme tema før dei byrjar å kode. Somme brukar lang tid på å
  velje. Pandaeksempelet kan brukast av dei som står fast.


# Steg 4: Bilete {.activity}

- [ ] `panda.svg` ligg ved sida av oppgåva, så han blir vist i Prøv selv-boksen.
  Elevane skriv deretter filnamnet feil med vilje og ser at alt-teksten blir
  vist. Snakk gjerne om kven som har nytte av alt-tekst: blinde og svaksynte med
  skjermlesar, og alle som har treg nettilkopling.

- [ ] Ein god alt-tekst skildrar det som er viktig på biletet, ikkje at det er
  eit bilete. *Teikning av ein panda som tyggjer på bambus* er betre enn *bilete
  av panda*.

- [ ] Prøv selv-boksen kan ikkje vise bilete frå maskina til eleven. Elevar som
  vil bruke eigne bilete, må jobbe i VS Code og leggje biletet i same mappe som
  `index.html`. Snakk om opphavsrett og personvern før elevane brukar bilete av
  andre eller frå nettet.


# Steg 5: Lenkjer {.activity}

- [ ] *Klikk her* seier ingenting når ein skjermlesar les opp alle lenkjene på
  sida. Be elevane skrive lenkjetekstar som gir meining åleine.


# Steg 6: Pynt med CSS {.activity}

- [ ] Elevane kan lime `<style>`-delen inn i si eiga side i staden for å byte
  til pandasida. Minn dei på at `<style>` skal stå inne i `<head>`.

- [ ] Prøv selv-boksen hugsar koden berre i den nettlesaren eleven brukar. Be
  elevane trykkje **Last ned som fil** før timen er slutt dersom dei skal jobbe
  vidare ein annan stad.

## Variasjonar {.challenge}

- [ ] Elevane kan lage sida i par, der den eine skriv innhaldet og den andre
  lagar stilen.

- [ ] Knyt oppgåva til eit tema frå eit anna fag, til dømes eit dyr i naturfag
  eller ein forfattar i norsk.

- [ ] La elevane teste sidene til kvarandre med ein skjermlesar, til dømes
  ChromeVox på Chromebook eller Skjermleser i Windows.
