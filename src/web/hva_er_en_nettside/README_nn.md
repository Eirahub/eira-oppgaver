# Om oppgåva {.activity}

Elevane finn ut kva ei nettside består av, og korleis nettlesaren gjer om tekst
til noko dei kan sjå og klikke på. Dei ser kjeldekoden til ei ekte nettside og
gjer dei første endringane sine i HTML, CSS og JavaScript, alt i Prøv
selv-boksar rett på sida. Ingenting må installerast.

## Oppgåva passar til: {.check}

__Fag__: Programmering, Kunst og handverk, IT1

__Tilrådde trinn__: 5. trinn til VG3

__Tema__: HTML, CSS, JavaScript, Web

__Nivå__: 1 (nybyrjar)

__Tidsbruk__: Éin skuletime

## Kompetansemål {.challenge}

Oppgåva kan brukast i arbeidet med kompetansemål om programmering og nettsider.
Sjå måla i læreplanane:

- [ ] [Læreplan i valfaget programmering
  (PRG01-02)](https://www.udir.no/lk20/prg01-02)

- [ ] [Læreplan i informasjonsteknologi
  (INF01-02)](https://www.udir.no/lk20/inf01-02), for IT1 og IT2

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan forklare kort kva som skjer frå ein skriv ei adresse til sida
  blir vist.

- [ ] Eleven kan seie kva jobb HTML, CSS og JavaScript har på ei nettside.

- [ ] Eleven kan endre tekst i HTML-taggar og forklare kva ein start- og
  slutt-tagg er.

- [ ] Eleven kan endre ein CSS-regel og forklare veljar, eigenskap og verdi.

## Forslag til vurderingskriterium {.challenge}

- [ ] Eleven oppnår middels måloppnåing ved å fullføre oppgåva.

- [ ] Eleven oppnår høg måloppnåing ved å løyse utfordringane og forklare med
  eigne ord kva koden gjer.

## Føresetnader og utstyr {.challenge}

- [ ] __Føresetnader__: Ingen. Elevane bør kunne bruke ein nettlesar og
  tastatur.

- [ ] __Utstyr__: Datamaskin med nettlesar og internett. Prøv selv-boksane
  verkar i alle moderne nettlesarar, også på Chromebook. Vil elevane jobbe med
  filer på eiga maskin, kan dei bruke VS Code (sjå oppgåva [VS
  Code](../vs_code/vs_code_nn.html)).

# Steg 1: Frå adresse til ferdig side {.activity}

- [ ] **Vis sidekjelde** (**Ctrl** + **U**) finst ikkje på alle nettbrett. På
  Chromebook verkar snøggtasten. Læraren kan òg vise sidekjelda på storskjerm.

- [ ] Kjeldekoden til store nettsider er lang og uoversiktleg. Poenget er berre
  å kjenne att taggar og tekst, ikkje å forstå alt.


# Steg 2: Den første HTML-en din {.activity}

- [ ] Prøv selv-boksen hugsar endringane i nettlesaren. **Tilbakestill** hentar
  den opphavlege koden. Det kan vere lurt å vise dette før elevane startar.

- [ ] Ein vanleg feil er å slette `<` eller `/` i ein slutt-tagg. Be elevane
  samanlikne med koden over når noko ser rart ut.


# Steg 4: JavaScript {.activity}

- [ ] JavaScript blir køyrt først når eleven trykkjer **Kjør** (eller lastar
  sida på nytt). Det hindrar at halvskriven kode heng nettlesaren.

- [ ] Elevane treng ikkje forstå `querySelector` og `addEventListener` enno.
  Målet er å sjå at dei tre språka jobbar saman i éi fil.

## Variasjonar {.challenge}

- [ ] La elevane finne ei nettside dei brukar ofte, og telje kor mange ulike
  taggar dei kjenner att i kjeldekoden.

- [ ] Elevane kan lage ei lita "visittkortside" om seg sjølve med ei overskrift,
  eit avsnitt og ein farge.
