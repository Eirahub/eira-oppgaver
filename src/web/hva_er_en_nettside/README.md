# Om oppgaven {.activity}

Elevene finner ut hva en nettside består av, og hvordan nettleseren gjør om
tekst til noe de kan se og klikke på. De ser kildekoden til en ekte nettside og
gjør sine første endringer i HTML, CSS og JavaScript, alt i Prøv selv-bokser
rett på siden. Ingenting må installeres.

## Oppgaven passer til: {.check}

__Fag__: Programmering, Kunst og håndverk, IT1

__Anbefalte trinn__: 5. trinn til VG3

__Tema__: HTML, CSS, JavaScript, Web

__Nivå__: 1 (nybegynner)

__Tidsbruk__: Én skoletime

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan forklare kort hva som skjer fra man skriver en adresse til
  siden vises.

- [ ] Eleven kan si hvilken jobb HTML, CSS og JavaScript har på en nettside.

- [ ] Eleven kan endre tekst i HTML-tagger og forklare hva en start- og
  slutt-tagg er.

- [ ] Eleven kan endre en CSS-regel og forklare velger, egenskap og verdi.

## Forslag til vurderingskriterier {.challenge}

- [ ] Eleven oppnår middels måloppnåelse ved å fullføre oppgaven.

- [ ] Eleven oppnår høy måloppnåelse ved å løse utfordringene og forklare med
  egne ord hva koden gjør.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: Ingen. Elevene bør kunne bruke en nettleser og
  tastatur.

- [ ] __Utstyr__: Datamaskin med nettleser og internett. Prøv selv-boksene
  virker i alle moderne nettlesere, også på Chromebook. Vil elevene jobbe med
  filer på egen maskin, kan de bruke VS Code (se oppgaven [VS
  Code](../vs_code/vs_code.html)).

# Steg 1: Fra adresse til ferdig side {.activity}

- [ ] **Vis sidekilde** (**Ctrl** + **U**) finnes ikke på alle nettbrett. På
  Chromebook virker hurtigtasten. Alternativt kan læreren vise sidekilden på
  storskjerm.

- [ ] Kildekoden til store nettsider er lang og uoversiktlig. Poenget er bare å
  kjenne igjen tagger og tekst, ikke å forstå alt.


# Steg 2: Din første HTML {.activity}

- [ ] Prøv selv-boksen husker endringene i nettleseren. **Tilbakestill** henter
  den opprinnelige koden. Det kan være lurt å vise dette før elevene starter.

- [ ] En vanlig feil er å slette `<` eller `/` i en slutt-tagg. Be elevene
  sammenligne med koden over når noe ser rart ut.


# Steg 4: JavaScript {.activity}

- [ ] JavaScript kjøres først når eleven trykker **Kjør** (eller laster siden på
  nytt). Det hindrer at halvskrevet kode henger nettleseren.

- [ ] Elevene trenger ikke forstå `querySelector` og `addEventListener` ennå.
  Målet er å se at de tre språkene jobber sammen i én fil.

## Variasjoner {.challenge}

- [ ] La elevene finne en nettside de bruker ofte, og telle hvor mange
  forskjellige tagger de kjenner igjen i kildekoden.

- [ ] Elevene kan lage en liten "visittkortside" om seg selv med en overskrift,
  et avsnitt og en farge.
