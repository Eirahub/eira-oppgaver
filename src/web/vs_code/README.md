# Om oppgaven {.activity}

Elevene installerer Visual Studio Code (VS Code), lager en mappe og en fil som
heter `index.html`, og ser siden i nettleseren. De lærer å bruke Emmet til å
lage et HTML-skjelett, utvidelsen Live Preview og automatisk lagring. Oppgaven
er broen fra Prøv selv-boksene til å jobbe med egne filer, flere sider og egne
bilder.

## Oppgaven passer til: {.check}

__Fag__: Programmering, IT1

__Anbefalte trinn__: 5. trinn til VG3

__Tema__: HTML, Web, Verktøy, Filer og mapper

__Nivå__: 1 (nybegynner)

__Tidsbruk__: Én skoletime, pluss tid til installering før økten

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan lage en mappe for et nettstedsprosjekt og åpne den i VS Code.

- [ ] Eleven kan lage og lagre en HTML-fil og åpne den i nettleseren.

- [ ] Eleven kan forklare forskjellen på å lagre i editoren og å laste siden på
  nytt i nettleseren.

- [ ] Eleven kan installere og bruke en utvidelse i VS Code.

## Forslag til vurderingskriterier {.challenge}

- [ ] Eleven oppnår middels måloppnåelse ved å fullføre oppgaven.

- [ ] Eleven oppnår høy måloppnåelse ved å lage flere sider som lenker til
  hverandre, og holde orden på filer og mapper.

## Forutsetninger og utstyr {.challenge}

- [ ] __Forutsetninger__: Det er lurt å ha gjort [Hva er en
  nettside?](../hva_er_en_nettside/hva_er_en_nettside.html). Elevene bør kunne
  lage mapper og finne filer på maskinen.

- [ ] __Utstyr__: Windows-, Mac- eller Linux-maskin der VS Code kan installeres.
  På skolemaskiner krever det ofte en administrator, så sjekk dette i god tid.
  VS Code kan ikke installeres på Chromebook eller nettbrett. Der kan elevene
  bruke Prøv selv-boksene i oppgavene og **Last ned som fil**, eller
  nettversjonen [vscode.dev](https://vscode.dev/) i en nettleser som støtter å
  åpne mapper (for eksempel Chrome).

## Fremgangsmåte

Her kommer tips og erfaringer til stegene i oppgaven. [Klikk her for å se
oppgaveteksten.](vs_code.html){target=_blank}


# Steg 1: Installer VS Code {.activity}

- [ ] Installer helst VS Code på alle maskinene før økten. Da kan timen brukes
  til å kode.


# Steg 2: Lag en mappe og åpne den {.activity}

- [ ] Mange elever har aldri laget en mappe selv. Vis det på storskjerm.

- [ ] Be elevene bruke små bokstaver og bindestrek i filnavn og mappenavn.
  Mellomrom og æøå kan gi trøbbel når siden publiseres.


# Steg 3: Lag index.html {.activity}

- [ ] Emmet-menyen kommer bare når fila heter noe som slutter på `.html`. Lager
  eleven fila uten endelse, kommer ikke menyen.

- [ ] Filer som er lastet ned fra en Prøv selv-boks, havner i **Nedlastinger**.
  Elevene må flytte dem inn i prosjektmappa.


# Steg 4: Se siden i nettleseren {.activity}

- [ ] Den vanligste feilen er å glemme å lagre eller å laste siden på nytt. Den
  hvite prikken på fanen i VS Code viser at fila ikke er lagret.


# Steg 5: Live Preview {.activity}

- [ ] På maskiner der elevene ikke kan installere utvidelser, kan steget hoppes
  over. Da dobbeltklikker de på fila og laster siden på nytt i nettleseren.

## Variasjoner {.challenge}

- [ ] Elevene kan flytte siden de laget i [Min første
  nettside](../min_forste_nettside/min_forste_nettside.html) over til VS Code og
  jobbe videre med egne bilder.

- [ ] Vis elevene snarveier i VS Code, for eksempel **Ctrl** + **/** for å
  kommentere ut en linje.
