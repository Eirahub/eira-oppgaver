# Om oppgåva {.activity}

Elevane installerer Visual Studio Code (VS Code), lagar ei mappe og ei fil som
heiter `index.html`, og ser sida i nettlesaren. Dei lærer å bruke Emmet til å
lage eit HTML-skjelett, utvidinga Live Preview og automatisk lagring. Oppgåva er
brua frå Prøv selv-boksane til å jobbe med eigne filer, fleire sider og eigne
bilete.

## Oppgåva passar til: {.check}

__Fag__: Programmering, IT1

__Tilrådde trinn__: 5. trinn til VG3

__Tema__: HTML, Web, Verktøy, Filer og mapper

__Nivå__: 1 (nybyrjar)

__Tidsbruk__: Éin skuletime, pluss tid til installering før økta

## Kompetansemål {.challenge}

Oppgåva kan brukast i arbeidet med kompetansemål om programmering og nettsider.
Sjå måla i læreplanane:

- [ ] [Læreplan i valfaget programmering

- [ ] [Læreplan i informasjonsteknologi

## Forslag til læringsmål {.challenge}

- [ ] Eleven kan lage ei mappe for eit nettstadprosjekt og opne ho i VS Code.

- [ ] Eleven kan lage og lagre ei HTML-fil og opne ho i nettlesaren.

- [ ] Eleven kan forklare skilnaden på å lagre i editoren og å laste sida på
  nytt i nettlesaren.

- [ ] Eleven kan installere og bruke ei utviding i VS Code.

## Forslag til vurderingskriterium {.challenge}

- [ ] Eleven oppnår middels måloppnåing ved å fullføre oppgåva.

- [ ] Eleven oppnår høg måloppnåing ved å lage fleire sider som lenkjer til
  kvarandre, og halde orden på filer og mapper.

## Føresetnader og utstyr {.challenge}

- [ ] __Føresetnader__: Det er lurt å ha gjort [Kva er ei
  nettside?](../hva_er_en_nettside/hva_er_en_nettside_nn.html). Elevane bør
  kunne lage mapper og finne filer på maskina.

- [ ] __Utstyr__: Windows-, Mac- eller Linux-maskin der VS Code kan
  installerast. På skulemaskiner krev det ofte ein administrator, så sjekk dette
  i god tid. VS Code kan ikkje installerast på Chromebook eller nettbrett. Der
  kan elevane bruke Prøv selv-boksane i oppgåvene og **Last ned som fil**, eller
  nettversjonen [vscode.dev](https://vscode.dev/) i ein nettlesar som støttar å
  opne mapper (til dømes Chrome).

## Framgangsmåte

Her kjem tips og erfaringar til stega i oppgåva. [Klikk her for å sjå

# Steg 1: Installer VS Code {.activity}

- [ ] Installer helst VS Code på alle maskinene før økta. Då kan timen brukast
  til å kode.


# Steg 2: Lag ei mappe og opne ho {.activity}

- [ ] Mange elevar har aldri laga ei mappe sjølve. Vis det på storskjerm.

- [ ] Be elevane bruke små bokstavar og bindestrek i filnamn og mappenamn.
  Mellomrom og æøå kan gi trøbbel når sida blir publisert.


# Steg 3: Lag index.html {.activity}

- [ ] Emmet-menyen kjem berre når fila heiter noko som sluttar på `.html`. Lagar
  eleven fila utan ending, kjem ikkje menyen.

- [ ] Filer som er lasta ned frå ein Prøv selv-boks, hamnar i **Nedlastingar**.
  Elevane må flytte dei inn i prosjektmappa.


# Steg 4: Sjå sida i nettlesaren {.activity}

- [ ] Den vanlegaste feilen er å gløyme å lagre eller å laste sida på nytt. Den
  kvite prikken på fana i VS Code viser at fila ikkje er lagra.


# Steg 5: Live Preview {.activity}

- [ ] På maskiner der elevane ikkje kan installere utvidingar, kan steget
  hoppast over. Då dobbeltklikkar dei på fila og lastar sida på nytt i
  nettlesaren.

## Variasjonar {.challenge}

- [ ] Elevane kan flytte sida dei laga i [Mi første
  nettside](../min_forste_nettside/min_forste_nettside_nn.html) over til VS Code
  og jobbe vidare med eigne bilete.

- [ ] Vis elevane snarvegar i VS Code, til dømes **Ctrl** + **/** for å
  kommentere ut ei linje.
